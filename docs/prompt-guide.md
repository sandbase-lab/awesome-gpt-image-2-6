# Prompt guide

This launch snapshot contains one reviewed static-image prompt. It supports one concrete pattern; it is not evidence for a general best-practices guide.

## 1. State the subject, action and setting

[The tea-at-home example](https://www.sandbase.ai/lab/prompts/gpt-image-2-6/2118147596891901957-tea-at-home) asks for “a realistic photo of a woman holding a cup of tea inside her home”. It names the rendering style, subject, action and location. Start by changing one of those details and inspect the resulting image. No claim is made that these words reproduce the original image exactly.

The creator did not publish the variant, seed or complete generation settings. The guide will expand as Lab accepts more sourced examples.
